# CcpaAuditLog

Filament plugin for laravel-ccpa-audit-log: the CCPA audit log in your panel, read-only, with who viewed, changed, exported or deleted personal information and a one-click hash chain check.

## Installation

You can install the package via composer:

```bash
composer require jeffersongoncalves/filament-ccpa-audit-log
```
